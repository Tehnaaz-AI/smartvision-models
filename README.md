# SmartVision

SmartVision is a modular AI project for smart glasses, developed with support
from the college incubation centre. Each model will live in its own subproject
so that its code, dependencies, datasets, and training workflow can be managed
independently.

## Model subprojects

- **OCRModel** — printed-text recognition, initially for medicine packaging.
- **TTSModel** — planned text-to-speech project.
- **ASRModel** — planned automatic speech-recognition project.
- **VisionModel** — planned image and video-frame understanding project.
- **VideoModel** — planned video-understanding project.

Only `OCRModel` is being developed at this stage. The other subprojects have
not been created.

See [OCRModel/README.md](OCRModel/README.md) for its setup and workflow.
